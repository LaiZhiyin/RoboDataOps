# Changelog

## 1.0.0 — 2026-11-08

- Four-page workbench: audit, evidence review, budget planning and cumulative snapshots.
- Five attributed public simulation video clips, metadata-based action/state seeking, strict FFmpeg decoding and explicit unverified states.
- ALOHA 14-channel/50 FPS compatibility cache, explicit unknown action semantics and evidenced business parameters.
- Bulk review/reopening, append-only history, immutable plans, scenario import/export and counterfactual/yield analyses.
- Source/type/contract-preserving cumulative snapshots, content/media conflict protection, review inheritance and duplicate receipt protection.
- Bilingual recruitment case study and README from one narrative source; real browser video and report-derived metrics.
- CLI, locked dependencies, wheel resources, Docker/Codespaces configurations, GitHub CI and Pages publication.

Independent human annotation, user comparisons, policy training/rollouts and real cost pilots remain unperformed. This release is a reproducible software and portfolio deliverable, not validated robot-policy or commercial effectiveness.

# 关键开发决策

| 决策 | 依据与取舍 | 验证 |
|---|---|---|
| 首版 Python/Streamlit 单体 | 把开发投入放在数据、SQL 与决策逻辑 | CLI 和页面共用模块 |
| 规则与人工结论分开 | 保留误报驳回与审计追踪 | 历史、幂等与状态回归 |
| 任务映射计入 snapshot | 相同数据但不同任务定义会改变验收 | 任务表变化反例 |
| 元数据整数禁止截断 | length=40.9 不能被静默当作40 | 非法长度和 shard index 回归 |
| 从真实列读取公开任务归属 | 固定 LIBERO metadata 无 tasks 字段 | 实际公开样本与 mocked fetch 两种布局 |
| 先按 episode 归约状态 | 防止多 findings 重复扣数 | SQL手算与复核更新 |
| 基础模型允许零分配 | 预算不足仍应返回剩余缺口 | 零预算、零产能、oracle |
| 回流核对原数据契约 | 同规则配置不代表同平台/schema | 平台、FPS、动作维度变化反例 |
| 到货串行去重 | 两连接各读空历史可能重复计功 | 重叠批次并发回归 |
| 导出明确草稿状态 | 公开数据缺动作单位、责任人和实际周期 | CSV包含完整配置并保留待确认项 |

以上是工程审查驱动的修改，不是虚构的用户访谈反馈。下一轮真实用户测试后，再追加“观察—修改—复测”的记录。

# English / 中文

The workbench and CLI default to English. Use **Language / 语言** in the sidebar, or `robodataops --lang zh audit ...` / `robodataops audit --lang zh ...` for Chinese. The website defaults to English and accepts `?lang=en#demo` and `?lang=zh#demo`.

`README.md` is the default English repository page. `README.zh-CN.md` contains Chinese copy; `README.en.md` is a compatibility alias for the English page. All three and the case study are generated by `script/build_portfolio.py` from `portfolio/content.json` and measured reports.

## Display contract

- `locales/en.json` maps the established Chinese product copy to English. Exact copy and explicit templates are translated. Unknown source text and captured paths/user inputs remain opaque; no substring translation of arbitrary content occurs.
- `i18n.py` uses a context-local language rather than shared mutable process state. `LocalizedUI` is an explicit rendering adapter, not a Streamlit monkey patch.
- Selectors return canonical options. Stateful widgets use stable keys derived from their original label, container scope and type. Formatters retain the language in which the widget was created.
- Display tables are copies. Raw JSON, source metadata, free-text reasons, downloaded plans and database records retain their original values. A language switch does not change data, audit or plan identities.
- Video seeking labels follow the current UI language; physical synchronization remains unverified.

## Recordings and playback

`python3 script/record_demo.py --lang en` records the actual English workbench and generates English captions plus an installed macOS Daniel system-TTS narration. `--lang zh` records the Chinese workbench and Chinese captions. Playwright/Chromium, FFmpeg and a running isolated app on port8503 plus site preview on8765 are authoring prerequisites. These optional recording tools are separate from the runtime dependencies.

The recordings, caption tracks and clickable play thumbnails use language-suffixed asset names. Hidden videos pause when switching language. URL deep links and browser back/forward restore the corresponding player. Videos do not autoplay; README thumbnails open the matching player and explicitly prompt the visitor to press ▶.

Verification includes catalog placeholder preservation, context isolation, unchanged audit settings/run IDs and plan/review round trips; real browser checks cover player selection, hidden-video pause, deep links, history, desktop and390px layouts.

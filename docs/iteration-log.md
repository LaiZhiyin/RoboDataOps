# 真实工程审查迭代

以下是开发与独立代码审查发现的工程问题，不是真人用户访谈。问题修复通过公开回归核查，V1不声称已取得产品效率或策略收益。

| 观察 | 判断与修改 | 复测证据 |
|---|---|---|
| 两个连接收货可能同时读取空历史，重叠来源重复计功 | 同一支持的本地进程用重入锁覆盖读取、去重、计算和事务写入 | tests/test_review_regressions.py 并发反例 |
| FFmpeg 输出损坏包错误时，默认退出码仍可能为0 | 使用 -xerror / 严格解码，并在error级别stderr非空时标无法解码 | tests/test_v1_regressions.py：退出0且有解码错误仍拒绝通过 |
| 表格相同但视频改变，旧视频驳回结论可能误迁移 | 轨迹证据身份包含metadata原区间、相机和文件SHA；内容冲突拒合并，变化证据不继承结论 | 两个不同色视频的累计冲突与复核不继承反例 |
| 累计快照只复制证据片段，可能丢掉已获取原片 | 同时保留原视频路径，文件冲突明确拒绝，生成后核查可完整解码 | 原片保留回归 |
| 求解未知可能被表格解释为“无改善”或“新增0条” | 反事实非最优保留未知，不作瓶颈结论；无解数量为空，并传递求解状态 | monkeypatch 超时无 incumbent 反例 |
| 长轨迹将所有向量值展开到 Math.min/max 触发浏览器参数上限 | 循环计算值域与维度，保留非有限值断线 | 浏览器10,000帧×14通道回归 |
| 网页与README数字容易分叉 | 共用content.json，数字读取实际报告；一致性检查进入CI | tests/test_portfolio.py、build_portfolio.py --check |

完整的原始现象、可运行测试、修复代码保留在Git版本中。后续真实用户反馈另建立独立记录。

# 贡献与开源归属

本项目使用 AI 辅助开发。核心新增实现包括产品流程、v3 薄适配、严格契约、质检与证据、复核状态、SQL 指标、预算模型、基线、到货核对和验证协议。开发者应亲自理解、复跑并能解释这些模块。

LeRobot 提供数据格式与生态；Hugging Face 提供公开数据托管；PyArrow 提供列式读取；DuckDB 提供数据库；SciPy/HiGHS 提供求解器；Streamlit 提供界面；pytest 提供回归框架。调用求解器不等于自行发明优化算法。

# 软件首版之后的验证

当前已具备离线软件闭环与自动化证据。以下工作需要新增真实参与者、数据或计算资源，不是已经取得的成果。

1. 依据 usability-protocol 招募3–5位相关用户，执行对照任务，保留一次实际反馈和复测。
2. 为真实公开样本建立独立人工标签，补充未告警样本和失败案例，不把合成指标外推为行业准确率。
3. 在Linux仿真环境选择2–4个任务，固定BC/ACT、预处理和训练预算，至少3个训练seed；质检筛选与预算分配分开消融。
4. 对比等预算的随机/均分、贪心和优化，任务内选择规则一致。用rollout任务成功率，报告训练种子波动和评测不确定性。
5. 进入一个团队的完整采集周期，收集实际工时、报价、成品率、返工和交付结果，再计算真实净收益。
6. 需求明确后，增加完整视频、可靠场景元数据、自动累计快照合并、多供应商和服务端协作。

GitHub Actions 已配置；需仓库上传到 GitHub 后才有远端运行记录。本地测试与浏览器验证不能写成远端 CI 已成功。项目尚未发布公网演示或执行真实策略训练。

# Reserved public delivery simulation pool

Source: [lerobot/libero](https://huggingface.co/datasets/lerobot/libero), pinned revision `a1aaacb7f6cd6ee5fb43120f673cebb0cfea7dd4`.

The dataset card declares Apache-2.0. License copy included; original LIBERO authors and LeRobot conversion maintainers retain attribution and rights.

This analysis cache selects four held-out complete episodes for each of the five baseline tasks (20 total), disjoint from data/public_sample. It simulates an incoming delivery using already existing public simulation data. It is not new physical collection, a real vendor delivery, or a policy experiment. Original metadata describes the full source and source shards remain unchanged. The manifest records IDs and SHA256. No videos are included in this pool. This is not a reindexed training split.
